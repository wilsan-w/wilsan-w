## Featured Projects

### Baby Monitoring System — FPGA & Embedded System

Designed a real-time embedded monitoring system using an FPGA-based architecture to detect critical infant health and environmental conditions.

**Technologies:** VHDL, FPGA DE1-SoC, ESP32, UART, I2C, Sensors

Key features:

- Implemented state-based control logic using FSM/ASM design
- Integrated ESP32 as a coprocessor for ADC and I2C sensor handling
- Processed heart rate, SpO2, gas/smoke, and sound sensor data
- Classified system states as Normal or Critical
- Built fail-safe alerts using LEDs, buzzer, and fan control
- Validated behavior through simulation, real-time testing, and edge-case scenarios

---

### Smart Cane & Secure Access System

Developed an assistive embedded system using Arduino and C++ for real-time obstacle detection and secure access control.

**Technologies:** C++, Arduino, Ultrasonic Sensors, Infrared Sensors, RFID, Servo Motor, LCD

Key features:

- Implemented real-time obstacle detection
- Designed adaptive audio and visual feedback logic
- Built RFID-based authentication
- Controlled servo-based secure access
- Modeled system behavior using finite state machines
- Integrated LCD displays, LEDs, and buzzers for user interaction
